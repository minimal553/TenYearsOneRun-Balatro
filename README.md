## 你的生日，不只是一个名字

在“输入生日”入口，出生信息会参与四柱排盘、格局小丑分配和大运表生成。你能在开局前看到：这一局以什么起手，接下来的大运会把门槛与奖励带向哪里。

| 命理概念 | 游戏中的表达 | 你要面对的选择 |
|---|---|---|
| **本命格局** | 一张对应格局的起手小丑；符合规则时附加一个组合效果 | 围绕它构筑，还是在商店转向？ |
| **十年大运** | 每升一个底注推进一步大运，重新确定过关倍率与运签 | 趁顺风积累，还是为逆风留后手？ |
| **运势起伏** | 原版基准的1至2倍门槛，配合九档不同奖励 | 道具什么时候用？这一步要怎样过？ |

![生日匹配实机：四柱、格局小丑与后续大运预览](docs/images/birthday-match.png)

*合成示例：匹配得到食神格，并可预览第六步大运。预览后续阶段不会跳关，确认后仍从第一步开始。*

## 一底注，十年运；每一步，都要重新出牌

保留Balatro熟悉的牌型、商店与小丑构筑。变化在于：**你的起手和沿途条件，都带着这张命盘的印记。**

- **起手有自己的性格。** 正官格偏向人头牌，食神格让非人头牌更有价值，阳刃格鼓励完整打出五张。26张卡不只是不同名字，也有不同的构筑入口。
- **大运会带来转折。** 生日模式按每步大运调整游戏档次，不是整局只贴一个“好运”标签；八个底注对应八步大运。
- **机遇要由你兑现。** 最顺的组合给原版灵魂，可以创造传奇小丑；其他阶段给幻灵、塔罗、增强牌或星球。它们保留原版的使用条件和取舍。

![食神格在真实牌局中参与计分](docs/images/birthday-gameplay.png)

*实机演示：专属小丑已进入牌桌，原版出牌与计分流程保持可玩。这里的“命运转化”是游戏体验，不是对现实人生的预测。*

## 顺运给你机遇，逆风考验构筑

本命档与当前大运档组成九档游戏条件。**第一档最顺，第九档门槛最高。**

| 档位 | 运签带来的机遇 |
|---|---|
| **1** | **灵魂**：使用后生成传奇小丑，须有空余小丑槽 |
| **2、3** | 一张随机**幻灵牌** |
| **4、5** | 两张随机**塔罗牌** |
| **6** | 两张倍率增强牌，或两张奖励筹码增强牌，各50% |
| **7、8** | 一张随机塔罗，或一张随机星球，各50% |
| **9** | 固定**冥王星**，提升高牌等级 |

![最顺组合获得原版灵魂的实机画面](docs/images/soul-reward.png)

*先使用大运签，再得到原版道具。灵魂何时使用由你决定；幻灵的原版代价、空位条件和其他使用限制仍然存在。*

## 想先玩一局？也可以不输入生日

“九宫预设”是快速试玩入口：直接选择“本命上／中／下 × 运上／中／下”中的一组，整局保持该档。九种预设统一使用常规命局小丑，不虚构个人四柱，也不调用生日分类器。

它适合先熟悉玩法；**想体验命盘与大运共同塑造牌局，请选择“输入生日”。**

## 开始你的这一局

1. 自行安装Balatro、Lovely和Steamodded。
2. [下载发行页的MOD安装包](https://github.com/minimal553/TenYearsOneRun-Balatro/releases/tag/v0.7.0)，关闭游戏，将其中的`TenYearsNineGrid`放入`%APPDATA%/Balatro/Mods`。
3. 启动游戏，选择青绿朱砂命盘牌背的**「十年一局·命局牌组」**，再进入**「输入生日」**。
4. 填写公历生日、北京时间和排运口径，预览后确认开局。时间可填`730`、`0730`或`7:30`。

**需要新开局才能体验0.7奖励表。** 旧存档保留原小丑、原档次和旧奖励，不重新判格，不覆盖已有存档。源码仓库包含高清美术；只想游玩时，下载较小的发行ZIP即可。
