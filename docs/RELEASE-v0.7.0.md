# 十年一局 v0.7.0 · Nine Paths, One Run

选择九宫挑战，或者输入生日生成这一局。26张格局起手小丑、九档难度与每步运签，保留熟悉的Balatro出牌构筑。

## 本次调整 / Updated rewards

- 第1档：1张原版灵魂，使用后生成传奇小丑，需空余小丑槽。
- 第2、3档：1张随机幻灵。
- 第4、5档：2张随机塔罗。
- 第6档：50%两张倍率增强扑克牌，50%两张奖励筹码增强扑克牌。
- 第7、8档：50%一张随机塔罗，50%一张随机星球。
- 第9档：固定冥王星（高牌升级）。

Rank1Soul; ranks2/3Spectral; ranks4/5two Tarot; rank6a same-type pair of Mult or Bonus playing cards; ranks7/8one random Tarot or Planet; rank9Pluto. The three either/or branches use equal probabilities.

## 安装 / Install

下载本页的`TenYearsNineGrid-0.7.0-*.zip`，关闭游戏，把其中`TenYearsNineGrid`目录放进`%APPDATA%/Balatro/Mods`。需要自行安装Lovely和Steamodded，不要复制整个源码仓库进入Mods，也不要删除存档。新开局采用新奖励表；旧局、旧票与已排队奖励保留原效果。

Download the packaged mod ZIP below, close Balatro and copy its`TenYearsNineGrid`folder into your Mods directory. Lovely and Steamodded are required and not bundled. Start a new run for the new reward table; old saves retain their previous promises.

## 验证与已知限制 / Verification and limits

2075条计数断言及其他分类/原生回调/图片检查通过；实机验证灵魂→传奇、冥王星升级、九档奖励、增强牌入手、排队、独立进程重开和旧票兼容。修复了领取动画中保存临时状态的风险。

**生日算法的官印相生漏识别仍未修复。** 本版不把“有分类结果”宣传为“判格准确”，所以标为开发预发行版。九宫预设不依赖该算法。没有上传用户生日、存档或游戏引擎文件。
