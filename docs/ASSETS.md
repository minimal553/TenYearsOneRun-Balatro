# Art provenance / 资源来源

- Artwork was generated with built-in ImageGen for this project. No Balatro texture atlas or Kingdom Rush screenshot is distributed as a new asset.
- The five runtime atlases are `deck`, `fortune`, `natal`, `patterns`, and `legacy_booster`, each at1x/2x. New card cells are71×95 and142×190.
- The26pattern cells consist of21new original compositions and5matching retained project artworks. All26cells are visually distinct. The old5-card natal atlas remains for saved-game compatibility.
- Retained mappings: `qisha→shayin-v2`, `zhengyin→guanyin-v1`, `shishen→shishang-v1`, `yuejie→bijie-v1`, `cong_cai→caixing-v1`.
- `tools/build_assets.cjs` performs aspect-preserving nearest-neighbor export and stepped transparent corners. It is not an image generator.
- Version0.6adds entry selection without changing the artwork or claiming a new aesthetic review.

Balatro and other referenced games belong to their respective owners. This is an unofficial mod. Existing third-party software licenses are retained separately; no new blanket license is asserted for the user's original work.
